# mihoyoCodexPets Skills

- Use the installed `hatch-pet` skill for creating Codex-compatible pet spritesheets.
- Keep generated run artifacts in `.pet-runs/<pet-name>/` and final game-specific spritesheets under the matching game folder.
- Must keep head-body ratio consistant through one pet generation. 
- Find a color doesn't exist in the target, use it as background.
